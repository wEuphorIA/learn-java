## 题目2

请使用单列集合完成如下操作

1.生成10个随机数，随机数范围在100~200之间

2.将10个数存入集合，遍历集合，并删除其中第3,7,9号位置的数字；

```
public static void main(String[] args) {
    Random random = new Random();
    List<Integer> list = new ArrayList<>();
    for (int i = 0; i < 10; i++) {
        list.add(random.nextInt(100, 201));
    }
    System.out.println(list);

    for (int i = list.size() - 1; i >= 0; i--) {
        if (i == 9 || i == 7 || i == 3){
            list.remove(i);
        }
    }
    System.out.println(list);
}
```
